# 웹페이지 정보 탐색 평가 (인간공학실험 5조)

AI 생성 서비스 소개 웹페이지의 시각 구조(AI 전형형, 위계 설계형)와 문구(일반적, 구체적)가 정보 탐색에 미치는 영향을 보는 2×2 참가자 내 실험 사이트입니다.

## 주소

| 용도 | 주소 |
|---|---|
| 참가자 링크 | `index.html` (첫 화면에서 참여 코드 입력: 본 실험 `UX5`, 파일럿 `PILOT5`, config.js의 CODES에서 변경) |
| 파일럿 | `index.html?pilot=1` (칸 지정: `&cell=1`~`8`) |
| 관리자 | `admin.html` |
| 화면 미리보기 | `index.html?preview=AG&service=schedule` |
| 이 브라우저 기록 초기화 | `index.html?pilot=1&reset=1` |

## 처음 한 번만: 데이터 저장 서버 연결

참가자 기록은 연구자의 구글 시트에 저장됩니다.

1. 구글 드라이브에서 새 스프레드시트를 만듭니다(이름 예: `5조 실험 데이터`).
2. 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `ADMIN_KEY`의 값을 원하는 관리자 비밀번호로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 > 새 배포 > 유형 선택(톱니바퀴) > 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한을 허용합니다("확인되지 않은 앱" 화면이 나오면 고급 > 이동).
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 `config.js`의 `ENDPOINT`에 넣습니다.

Code.gs를 고친 뒤에는 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포**를 해야 반영됩니다(주소는 그대로).

## 진행 순서

1. **파일럿**: `?pilot=1`로 2~3명 진행 → 관리자 페이지 **파일럿 점검** 탭에서 소요 시간, 시간 초과, 모든 조건 90% 이상 과업을 확인합니다.
2. 필요하면 `content.js`(과업, 보기, 페이지 내용)나 `config.js`(제한시간)를 고칩니다.
3. **리허설**: 연구진이 처음부터 끝까지 한 번 진행해 기록과 배정을 확인합니다.
4. 파일럿 자료를 **내려받기** 탭에서 받아 둔 뒤 **파일럿 점검** 탭에서 삭제합니다.
5. **본 실험**: 참가자 링크를 공유합니다. 칸은 접속 순서대로 자동 배정되고, 중단하거나 제외 처리한 참가자 자리는 같은 칸으로 다시 채워집니다.
6. 끝나면 **내려받기** 탭에서 분석용 CSV를 받습니다(`include` 열이 1인 행만 분석).

## 기록 규칙 (예비보고서 3.2, 3.5와 같음)

- 이벤트(TEN): 상호작용 요소(링크, 버튼 등) 클릭과 응답 선택, 뒤로 가기.
- 반응 없는 영역 클릭은 TEN에서 빼고 `non_interactive_clicks`로 따로 기록.
- 같은 요소를 0.5초 안에 다시 누르면 한 번으로 셈.
- 스크롤은 TEN에서 빼고 최대 깊이(`max_scroll_pct`)만 기록.
- 과업 중 탭 이탈 10초 이상이면 `exclude_tab=1`로 분석에서 제외.
- 오답과 시간 초과는 `tct_censored=90`, `event=0`으로 중도절단 표시.
- 이벤트 효율(`event_eff`) = Min TEN / TEN × 100, 정답 과업에서만 계산.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `config.js` | 서버 주소, 제한시간, 최소 창 크기, 문의처 |
| `content.js` | 서비스 4종의 문구 2종, 과업, 퀴즈, 연습 과업 |
| `templates.js` | 시각 구조 템플릿 2종(AI 전형형, 위계 설계형) |
| `logger.js` | 클릭, 뒤로 가기, 스크롤, 탭 이탈 기록 |
| `app.js` | 실험 진행 흐름 |
| `api.js` | 서버 전송(실패하면 다시 시도) |
| `admin.html`, `admin.js` | 관리자 페이지 |
| `apps-script/Code.gs` | 구글 시트 저장 서버 |
